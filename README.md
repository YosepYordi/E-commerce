# 🛒 E-commerce Spring Boot API & Web Application

Sistema de comercio electrónico desarrollado con Spring Boot, Spring Data JPA y H2 Database. El proyecto incluye una API REST para la gestión de productos y carrito de compras, además de una interfaz web construida con HTML, CSS y JavaScript.

# 📝 Descripción del Proyecto

E-commerce es una aplicación web orientada a la gestión de un catálogo de productos y un carrito de compras.

Principales funcionalidades:

- Consulta de catálogo de productos.
- Búsqueda y filtrado por categorías.
- Gestión de productos mediante API REST.
- Carrito de compras basado en sesión HTTP.
- Validación de stock.
- Manejo centralizado de errores.
- Persistencia mediante base de datos H2.
